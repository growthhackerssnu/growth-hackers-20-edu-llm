# 여행 일정 에이전트 만들기

LLM 에이전트를 직접 만들어 보는 과제입니다. 루프와 데모 사이트는 이미 있습니다.
여러분은 **툴 두 번째부터**와 **시스템 프롬프트**를 씁니다.

## 시작하기

```bash
sh init.sh                  # uv 설치 + 의존성 설치 + .env 생성 + 자체 점검
```

Windows 는 **Git Bash** 에서 같은 명령을 실행하세요. (`sh init.sh`)

그다음 `.env` 를 열어 발급받은 `OPENAI_API_KEY` 를 채우고:

```bash
uv run streamlit run app.py
```

터미널에서만 돌려보고 싶으면:

```bash
uv run python agent.py "서울에서 파리 3일 일정 짜줘"
uv run python mock_api.py                      # 가짜 API 점검 (키 없이도 됩니다)
```

## 파일 지도

| 파일 | 내용 | 수정 |
|---|---|---|
| `agent.py` | 에이전트 루프. 모델에 묻고, 툴을 부르고, 결과를 다시 넣는 40줄 | ✗ |
| `registry.py` | `@tool` 데코레이터. 타입힌트와 docstring 으로 툴 스키마를 만든다 | ✗ |
| `mock_api.py` | 가짜 여행 API. 실제 서비스처럼 가공되지 않은 원본 데이터를 준다 | ✗ |
| `app.py` | Streamlit 데모 사이트. 툴 호출 과정도 같이 보여준다 | ✗ |
| **`tools.py`** | **여러분의 툴** | ✓ |
| **`prompts.py`** | **여러분의 시스템 프롬프트** | ✓ |

먼저 `agent.py` 를 한 번 읽어보세요. 40줄이고, 에이전트의 전부입니다.

## 해야 할 일

1. **`tools.py`** — `get_weather` 예시를 보고, 툴을 **3개 이상** 더 만드세요.
   `mock_api` 는 `1756742400`, `81200000`, `rating_x10: 42` 같은 값을 그대로 줍니다.
   이걸 모델이 읽을 수 있는 문장으로 바꾸는 것이 툴의 일입니다.
2. **`prompts.py`** — 에이전트의 역할, 툴 사용 규칙, 일정 출력 형식, 실패 처리를 쓰세요.
3. 데모 사이트에서 실제로 일정을 뽑아보고, 이상하면 툴이나 프롬프트를 고치세요.

## 제출

- 이 저장소를 그대로 (수정한 `tools.py`, `prompts.py` 포함) 제출합니다.
- `.env` 는 올리지 마세요.
- 데모 대화 스크린샷 1장 또는 대화 로그를 같이 냅니다.

## 규칙

**AI 코딩 도구 사용 금지입니다.** (Copilot, Cursor, Claude Code, ChatGPT 코드 생성 등)
코드는 짧습니다. 직접 쓰세요. 툴을 왜 그렇게 나눴는지, 프롬프트를 왜 그렇게 썼는지
설명하지 못하면 점수가 없습니다.

## 평가

| 항목 | 보는 것 |
|---|---|
| 툴 설계 | 툴이 하는 일이 하나로 명확한가. docstring 만 보고 언제 쓸지 알 수 있는가 |
| 데이터 가공 | 원본 코드/타임스탬프/최소 단위 금액을 사람이 읽을 형태로 바꿨는가 |
| 예외 처리 | 없는 도시, 잘못된 날짜에 에이전트가 무너지지 않는가 |
| 프롬프트 | 툴을 제때 부르고, 지어내지 않고, 일정 형식이 일관적인가 |
| 결과 | 나온 일정이 실제로 말이 되는가 (날짜 순서, 이동, 예산) |
